# Hardware validation checklist

Use the supported Mac or Raspberry Pi host and CDJs on the same local network. Record player models, firmware and results locally.

1. Verify discovery and manual-IP connections, metadata, artwork and waveforms.
2. Check play/pause, tempo, master and sync status against the players.
3. Change tracks and USB sources; confirm that metadata and waveforms switch together.
4. Check position, phrase boundaries and waveform alignment during playback, seeks and loops.
5. Disconnect and reconnect players, USB media and the network; verify recovery.
6. Validate explicit track-load requests and active-player protections.
7. Check history recording, editing, persistence and file exports.
8. Verify native window lifecycle and simultaneous LAN browser access.
9. On Raspberry Pi, check touch, rotation, on-screen keyboard and sustained rendering performance.

Position on older players remains an estimate; do not claim precise sub-beat scratch tracking. See [distribution validation](build-validation.md) for outstanding platform checks.
