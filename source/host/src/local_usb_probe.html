Local USB playback test

Serve one original WAV from the USB. This tests storage and network playback; it does not read OneLibrary yet. No transcoding or remote load/play commands.

  1. Keep OLC in the foreground. Disconnect live mode in MENU.
  2. Choose a stereo PCM WAV (44.1/48 kHz, 16/24-bit) from the USB under Files → Browse. The file stays on the USB.
  3. Use an isolated test network with one physical CDJ. Confirm the virtual source number is unused.
  4. Start serving, then on the CDJ press LINK, select OLC USB TEST, open TRACK and load the selected file. Start playback manually.
  5. Check audible playback for at least two minutes, then seek and loop. Stop playback before stopping this test or leaving the app.
